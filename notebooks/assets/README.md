# Open Sans asset provenance

The user-selected Deloitte Data Design system specifies Open Sans for notebook and HTML output. The bundled Latin variable WOFF2 font supports weights 400–700 without a runtime network request. Other scripts or symbols can use the declared system-font fallbacks.
